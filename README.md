## 🚀 Featured projects

### 🧱 [OPNsense Firewall Practice Lab](https://github.com/SiriBandaru13/opnsense-firewall-lab)
> `OPNsense` `VMware` `Kali Linux` `Firewall rules` `NAT` `Log analysis`

A trust/untrust firewall lab with four drills: default deny, DNS/HTTPS-only rules, rule ordering (a shadowed block rule) and source NAT. Every drill is documented with the change, the failure, the log evidence and the fix. Built on OPNsense to practise the same concepts used on Palo Alto firewalls (zones, top-down policy, NAT, traffic logs).

### 🔒 [AWS Cloud Security Monitoring Dashboard](https://github.com/SiriBandaru13/aws-cloud-security-dashboard)
> `AWS` `CloudTrail` `CloudWatch` `Lambda` `SNS` `EventBridge` `Python`

A cloud security monitoring system with custom CloudWatch metric filters, Python Lambda auto-remediation triggered by EventBridge, SNS alerts and a real-time 6-widget security dashboard.

### 🧠 ASD Detection & Therapy Recommendations
> `ResNet101` `Random Forest` `Flask` `Python`

A two-model approach: **ResNet101** for image/video analysis and **Random Forest** for behavioural data, combined into a Flask app that gives real-time predictions and personalised therapy recommendations.
